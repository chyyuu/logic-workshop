## 审阅发现与修复

独立只读审阅确认四项具体问题，均已修复并复查：

1. 第50关预算只按第二个加数计算，会误拒交换加数的正确算法。已按最大操作数计算，并用真实门级交换算法完成失败→通过回归。
2. 第44关进入编程关再返回，旧Worker会话可能继承CPU周期9。已清理旧状态；真实消息回归验证返回周期0、PC/A/Out/Halt为0。
3. 编程图把E/R输入一起设为只读。已增加工作台E/R控制并开放CPU图输入，固定电气结构仍受校验保护。
4. 应用相同汇编只增加revision，不会重启。浏览器先复现周期9没有归零；现每次应用递增会话epoch，重新载入选中用例。

原数据通路展开测试在CPU争用时超过5秒；该重型用例等待调整为30秒，断言未改。完整时序等价检查在场景间交还Node事件循环以处理Vitest进度，所有场景及比较仍保留。
