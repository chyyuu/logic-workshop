# 逻辑工坊：20 关与组件复用

从信号连线开始，逐步搭建逻辑门、选择器、半加器、全加器、四位加法器与减法器。

## 运行

需要 Node.js 20.19+ 或 22.12+。在本目录运行：

```powershell
npm.cmd install
npm.cmd run dev -- --port 5173
```

打开 http://127.0.0.1:5173/ 。首次进入第一关，通过后依次解锁后续关卡。

也可运行 `npm.cmd run start:local` 启动隐藏的后台开发服务；PID 保存在 `server.pid`，日志在 `server.log` 和 `server-error.log`。需要其他端口时运行 `npm.cmd run start:local -- 5174`。停止自己启动的服务可根据 `server.pid` 用 `Stop-Process -Id <PID>`。

局域网访问可运行 `npm.cmd run dev -- --host 0.0.0.0 --port 5173`，其他设备使用本机局域网 IP 与端口访问。随机 ID 生成兼容局域网 HTTP 环境。公网部署可将 `dist/` 放到静态 HTTPS 服务。

使用时可以从输出端口拖到输入端口，也可以依次点击两个端口。点击输入节点切换 0/1，点击测试运行全部输入组合。点选逻辑门或导线后可以删除；固定输入输出不可删除。输入已有导线时，先删除旧连接。

拖动空白区域框选，按住空格或中键拖动平移；支持缩放与适应画布。Ctrl+Z 撤销，Ctrl+Shift+Z / Ctrl+Y 重做，Delete 删除，Ctrl+D 复制所选逻辑门及其内部连接。

## 已实现

- 20 关，覆盖基础逻辑、选择与分配、总线与比较、加减运算。
- 鼠标拖动与点击连线、逻辑门拖放、节点移动、框选、复制、删除、撤销重做。
- 1/2/4 位信号、部分未知位、多输出接口、总线拆分与合并、可配置常量。
- 独立数学参考函数的穷举判题；失败输入自动复现，输出和相关导线高亮。
- 三层提示、关卡解锁、每关独立草稿和独立通关证明。
- 自动存档、JSON 导入导出；导入重新验证证明；存储失败持续提示。
- 桌面工作台、平板与手机抽屉布局。
- 通过后保存整个电路为组件；所选电路可封装成组件实例；组件可嵌套、复用、查看内部电路或展开。
- 同名组件保存为新版本，旧实例继续引用原版本。所有输入、输出和内部连接随组件保存。
- 实时仿真、穷举判题、存档解析与证明验证在 Web Worker 中执行；大型真值表分页展示，后台任务可以取消。

## 仿真与当前范围

计算使用 DigitalJS 0.14.2 的 HeadlessCircuit 和 SynchEngine；显示与编辑使用 React Flow。NOT 实际编译成两个输入绑定在一起的 NAND，符合第三关原理。

当前支持组合逻辑，不模拟时钟、寄存器或真实电气传播时间。反馈回路、多驱动、位宽不一致、缺失或递归组件依赖在仿真前拒绝。每个可见电路最多 200 个节点、400 条连接；嵌套展开最多 2,000 个节点、5,000 条连接，深度最多 16 层。组件库最多保存 256 个版本，存档最多 4 MB。

后台判题编译一次电路并复用引擎遍历所有输入；实时信号与完整判题使用不同线程，编辑或切换关卡会取消过期判题。仿真依赖当前锁定的 SynchEngine 在返回已完成 Promise 前提交信号的行为，升级仿真库必须重跑测试。

历史通关证明独立于当前编辑草稿，因此修改或重置不会抹掉学习进度，但旧测试结果不会证明新草稿正确。存档包含 20 关草稿、证明、输入值及完整组件库，包括嵌套依赖与旧版本。旧四关存档自动迁移。导入先在后台完成结构检查与证明重验，成功后一次性替换工作区。

撤销恢复节点、位置、参数和全部连接，封装、展开、复制、删除与重置均可撤销。不可变组件版本保留在库中，以保护草稿及通关证明的引用。撤销历史、当前选择与临时判题结果不跨刷新保存。

手机可通过抽屉查看任务与添加组件，画布自动缩放；完整编辑体验优先针对桌面。导入会替换此应用的整个存档，仅在格式与全部电路合法后执行。

浏览器验收包含 512 组输入的后台判题，并在判题期间切换输入及检查动画帧持续推进。第三方仿真库仍带来较大的构建包；生产部署建议启用压缩和静态资源缓存。

## 验证

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run test:e2e
```

浏览器测试使用 Playwright。当前机器已有 Chromium 时使用本机安装；其他机器可先运行 `npx.cmd playwright install chromium`。

测试用参考电路位于 `tests/fixtures.ts`。全部 20 关覆盖 1,672 组输入，其中第 12、18 关各 512 组。验收还覆盖多输出反例回放、嵌套封装等价、组件版本、依赖循环与缺失、深层展开、完整撤销、存档迁移、导入导出、保存失败和响应式布局。

本次验收通过 57 项单元测试、18 项生产版浏览器测试和生产构建，详见 [验收记录](docs/acceptance-report.md)。

构建产物在 `dist/`，可通过静态 HTTP/HTTPS 服务部署。不要直接以 file:// 打开模块应用。
