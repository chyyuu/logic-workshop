# 状态与时间阶段设计

本次只交付第 21–32 关。用户要求每完成一个阶段暂停试玩，因此计算机架构和编程应用在阶段验收后继续。

## 时序与电路

系统提供 DFF 原语，位宽支持 1、2、4、8，输入 d 与 rst，输出 q。所有 DFF 使用隐式统一时钟，无时钟门控。初始状态为 0，rst 同步且优先；未知复位或数据按三值逻辑处理。未连的输入保持 X。

一个周期：组合求稳 → 全部 DFF 采样旧状态 → 同时提交新状态 → 再求稳。只改变输入时不推进时钟。组件实例通过内部实例路径分别拥有状态。组合反馈仍拒绝；含寄存器的反馈在展开后的实际端口依赖图上验证，不能把整个封装组件误当成时序边界。

现有 DigitalJS 组合仿真保留。时序适配层把 DFF 的 q 当成状态源、d/rst 当成采样点，使用同一组合引擎求稳，以显式统一提交保证语义。

## 交互与反馈

时序关卡提供运行/暂停、单步周期、清零状态、周期数和波形记录。输入修改立即更新组合信号；连续运行使用当前输入。波形最多保留最近 64 次观察。结构变化、切关、导入和刷新从初始状态开始，移动节点不重置状态。

时序测试显示场景、步骤、输入、预期、实际和结果，每页最多 8 行。反例回放从该场景的初始状态开始执行完整前缀，恢复失败时的内部状态与输入。正常试验输入改变后，旧反例高亮消失，仍可回放。
